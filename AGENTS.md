# Agent Instructions & Project Guidelines

## Mandatory Requirement: Record All Updates in `design.md`
Every time an AI agent makes any modifications, additions, or deletions to code, configuration, or documentation in this repository:
- You **MUST** record the update in `design.md` under **Section 8: Changelog & Update History**.
- Include timestamp, actor, type of change, affected components, and summary of changes.
- Never finalize a turn without updating `design.md` if any project modifications were made.
